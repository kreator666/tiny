# 玩法规则

## 1. 建造规则

- 所有建筑必须建在地图网格（40 × 30）内空地：不能有树、不能有其他建筑（含大院占地）。
- **除田/路外，建筑需邻接道路才会激活**（生产、派出行人、招工均以邻路为前提）。
- 造价从金钱扣除；DEBUG 模式下全部免费。
- 拆除工具：返还半价；树木付费砍除；大院按等级退款。

## 2. 道路与行人（服务机制）

- 建筑靠**行人随机巡行**向沿路民居提供服务，而非玩家指派。
- 行人类型与来源：

| 行人 | 来源 | 作用 |
| --- | --- | --- |
| 居民 | 民居/大院 | 使民居"被服务"（演进条件） |
| 挑夫 | 粮油店 | 同上 |
| 挑水夫 | 水井 | 使民居"有水喝"（翻修前提） |
| 伐木工 | 伐木屋 | 砍路边树 +1 木材 |
| 郎中 | 医馆 | 诊治（瘟疫减伤八成） |
| 工匠 | 维修站 | 修缮邻路建筑 / 灭火 |

- 行人每 3 秒从各建筑派一波，每波最多走 20 步，全局上限 80 人。
- "最近 3 个月内有服务/供水/诊治"计为达标。

## 3. 岗位与生产效率

- **人口即劳力**：每月按建筑放置顺序依次填满岗位，招不满则按在岗比例减产。
- 维护度影响：≥60 满产，30–59 半产，<30 停产。
- 维护度每月自然衰减（道路不衰减）；维修站工匠或花钱修缮可恢复。

## 4. 住房演进

```
茅屋(1格,4人) ──3个月──> 瓦房(1格,8人) ──3个月+2x2空地──> 宅院(2x2,32人) ──4个月──> 豪华大宅(2x2,48人)
   需：吃饱+服务+水喝            需：吃饱+服务                    需：吃饱+服务                     另需：每月消耗 1 份二级食品
```

- 条件断档时进度减半（不清零）。
- 2x2 合并：四格内为瓦房或空地即可成院，会自动吞并相邻瓦房。
- 容量：茅屋 4 ｜ 瓦房 8 ｜ 宅院 32 ｜ 豪华大宅 48。
- 居民迁入：吃饱且有空房时，每月迁入 `max(2, 空房 × 25% × 移民增速)`。

## 5. 时间

- 每 2 秒 = 1 个月；12 个月为一年。
- 每年自动存档一次（静默）。

## 6. 灾害与随机事件

月均触发概率 4% × 事件系数：

| 事件 | 效果 | 应对 |
| --- | --- | --- |
| 火灾 | 建筑起火，2 个月后烧毁 | 维修站工匠扑灭（2 木材） |
| 瘟疫 | 流行 3 个月，每月病亡 12% × (1 − 诊治覆盖 × 0.85) | 医馆郎中巡诊 |
| 丰收 | 五种作物田各 +10 产量 | 白捡 |
| 蝗灾 | 6 个月内作物田产量减半 | 囤粮 |

DEBUG 模式下：火灾不烧毁、瘟疫不病亡。

## 7. 存档

- 3 个手动存档位 + 1 个自动存档位，主菜单可读档。
- 存档包含：全部资源、建筑/大院/树、维护度、诏令、难度。
- 旧版本存档自动兼容（旧"粮食"折算为水稻）。

## 8. 操作

| 操作 | 键位 |
| --- | --- |
| 建造/查看 | 左键 |
| 取消工具 / 关闭面板 | 右键 / Esc |
| 平移视角 | 中键拖拽 / WASD / 方向键 |
| 缩放 | 滚轮（以鼠标为中心） |
| 旋转 90° | Q / E |
| 存档/读档/难度/返回菜单 | 顶部导航条 |

## 9. DEBUG 模式（仅开发者）

- 启动方式：命令行 `xinsong-zhisuo.exe -- --debug`，或双击 `tools/run_debug.bat`；最终用户双击 exe 无法进入。
- 效果：各项数值**只增不减**——资源不消耗、百姓永不挨饿、人口不流失、维护度不衰减、火灾不烧毁、建造修缮免费、诏令扣款豁免、净收入为负不扣钱。
- **禁止存档**（手动拒绝 + 自动跳过），防止污染存档位；读档不受影响。
- 顶栏与主菜单显示红色 "DEBUG" 标识。
