# 视觉升级方案（建筑立体感 / 动画 / 比例）

> 状态：已与负责人确认选型 —— CELL→48、程序化 3/4 重绘、动画四项全做（水车/炊烟/行人/火灾）
> 依据版本：git `18fa781`

## 1. 目标与参考

对标《凯撒大帝3》《法老王》的 2D 表现：建筑呈 3/4 俯视立体感（见屋顶平面、双墙面明暗、落地影），画面有常驻微动画，主体在屏幕上占比足够大、细节可辨。

## 2. 现状问题

| 问题 | 根因 |
| --- | --- |
| 建筑像纸片 | 贴图为正面立面画法（`tools/gen_gongbi_assets.py` 的 paint_house 等），无顶面、无侧墙明暗、无投影 |
| 看不清 | 1 格建筑贴图仅 32×32；地块 CELL=32、默认缩放 1.0 |
| 画面死板 | `_draw` 全静态，无任何逐帧动画；`_process` 只在有行人时重绘 |
| 大宅偏移脆弱 | `ESTATE_GROUND_OFF` 8 个值逐图人工标定，换贴图即失效 |

## 3. 方案

### 3.1 贴图重绘（tools/gen_gongbi_assets.py v2，程序化）

画法规范（所有立牌建筑统一）：
- **3/4 俯视伪透视**：平行四边形屋顶 + 瓦垄墨线 + 正脊；左右墙面双色（受光面亮 / 背光面暗约 -25% 明度）；侧山墙收边。
- **落地影**：每张贴图底部固定位置画椭圆阴影（锚点 = 图宽中心, 图高 -8），供代码计算偏移。
- **底色**：保留宣纸底 + 矿物色（花青瓦/赭石木/石绿），与 UI 风格一致。
- 建筑点缀按类型区分（酒坛/榨油架/布架/粮袋/灯笼等，延续 v1 思路但按新透视重画）。

输出规格（CELL=48 配套）：

| 类别 | 文件 | 尺寸 |
| --- | --- | --- |
| 地块 | ground_0/1、road*.png、farm/wheat/cotton/soy/grape | 48×48 |
| 1 格立牌 | hut/house/mill/market/grocer/winery/oilpress/loom/woodcutter/well/clinic/repair ×d0-d3 | 96×96 |
| 大宅 | estate2/3 ×d0-d3 | 144×120 |
| 树/行人 | tree.png / villager.png | 60×84 / 18×30 |

新增：gongbi 包此前缺 well/clinic/repair（一直靠 gongbi_ai 回退），v2 一并补齐。

### 3.2 比例调整（CELL 32→48）

- `main.gd` `CELL := 48`，地图世界尺寸同比例放大，坐标逻辑全部自动适配（输入、投影、小地图均按 CELL 派生）。
- `HUD_WIDTH 284→332`，视角中心与右侧 320px 导航栏对齐。
- 立牌/树/行人的绘制偏移由硬编码改为按贴图尺寸公式：`( -w/2, 底部留白 - h )`（原 32px 贴图的 `(-16,-30)` 即该公式特例），消除魔法数。
- `ESTATE_GROUND_OFF` 废除人工标定：大宅贴图锚点统一（底影中心 = 图宽中心, 图高-8），偏移由 `_estate_offset(tier)` 按贴图尺寸计算，四方向同值。

### 3.3 动画（程序绘制，零新增贴图）

时间源：`_process` 累加 `_anim_t` 并每帧 `queue_redraw()`。

| 动画 | 实现 |
| --- | --- |
| 烟囱冒烟 | 磨坊/酒坊/油坊/酒楼（`SMOKE_BUILDINGS` 表，含屋顶出烟点）每建筑 3 个烟圈，相位错开：半径渐大、alpha 渐隐、匀速上浮，正弦摆动 |
| 磨坊水车 | 水车从贴图剥离，程序绘制：圆环 + 8 辐条 + 叶片，角速度恒定；右侧建筑画在右、左侧画在左 |
| 行人起伏 | 行走时 y 轴 ±2px 弹跳（相位按行人位置错开），六类行人颜色区分保留 |
| 火灾跳焰 | 着火建筑上方 2~3 簇火苗（橙/黄多边形），高度随 sin 抖动，替代现在的静态泛红 |

### 3.4 素材包切换

`data/pack.json` active 由 `gongbi_ai` 改为 `gongbi`：AI 包贴图是旧 32px 正面画法，与新贴图混用会风格/尺寸错乱。后续如需 AI 画风，用 `gen_ai_assets.py` 按新规格重生成后再切回。

## 4. 实施步骤

1. 重写 `gen_gongbi_assets.py` 全部 painter（3/4 透视 + 新尺寸），运行生成，PIL 校验尺寸清单
2. `main.gd`：CELL 48、HUD_WIDTH、偏移公式化、ESTATE 偏移计算化
3. `main.gd`：四项动画 + 每帧重绘
4. `data/pack.json` 切回 gongbi；`godot --import` 导入新贴图
5. 回归：`test_crops` / `test_evolve` / `test_debug` / `test_roads`
6. 截图验证：非无头跑主场景摆示范城市截 2~3 张视角图，人工核对立体感/比例/动画帧
7. 导出 exe 并启动实机确认

## 5. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 3/4 伪透视程序画不好，效果仍平 | 先重画 mill/market/hut 三张样板人工确认，再批量推广 |
| 大宅偏移计算与实际贴图锚点不符 | 第 6 步截图核对，必要时单调锚点常量 |
| 每帧重绘的性能 | 同屏 ≤1200 地块 + ≤80 行人，Godot 2D 足够；如卡顿再改脏矩形 |
| gongbi_ai 玩家切回旧包导致尺寸错乱 | 两个包都保留旧文件不受影响；新文件只进 gongbi |

## 6. 验收标准

- 1 格建筑占据约 2×32px 屏幕高度细节可辨，大宅占 2×2 地块且不漂移（四方向旋转无错位）
- 静止观察 10 秒可见：烟在飘、水车在转、行人有步伐感
- 着火建筑有明显跳焰
- 全部回归测试通过；存档兼容（CELL 不入存档）
